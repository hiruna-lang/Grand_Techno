# Grand Techno website

Client website built with HTML, CSS and JavaScript.

## Open locally

Open this project in VS Code and use Live Server on the root `index.html`. It opens the website in `grand-techno/`. No installation is required to view the site.

The seven website pages and all required assets are in `grand-techno/`. See [project instructions](grand-techno/README.md) for the file structure and editing workflow.
