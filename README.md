# Grand Techno

Multi-page website for Grand Techno in Alupathwila, Sri Lanka, featuring its restaurant, leisure park, celebrations, gardens and cottage-style spaces.

Built with HTML, CSS, vanilla JavaScript, GSAP and ScrollTrigger. Includes real venue photography, responsive layouts, a filterable gallery, a photo viewer and WhatsApp inquiries.

## Run locally

Open this repository in VS Code and use **Live Server** on `index.html`. The root page opens the website inside `grand-techno/`. No installation or build is required.

Alternatively, run `python -m http.server 5500` and visit `http://localhost:5500`.

WhatsApp and calls use **+94 72 483 2444**. No backend is required; visitors review and send their inquiries through WhatsApp.

See [website setup and editing instructions](grand-techno/README.md) and [verification notes](grand-techno/QA.md). Opening hours, official social profiles and the exact map location still need confirmation.
